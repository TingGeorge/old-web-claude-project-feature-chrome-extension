How to use

  • Click the folder + next to Folders in the claude.ai sidebar to make a folder.
  • Drag chats from Recents onto a folder, or right-click a chat → Add to folder.
  • Hover a folder and click the pencil icon to start a new chat that's filed there automatically.
  • Drag folders onto each other to nest them. Double-click a name to rename it.
